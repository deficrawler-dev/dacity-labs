A few things to know

Good questions.

What can I try right now?

Signal Test is a working browser demo on this page. Flight Mode is a planned concept. More experiments can be added as they become ready.

Does playing earn tokens or prizes?

No. Signal Test is a free reaction game. There are no token rewards, payouts, or financial prizes. Your personal best is stored only in your browser when storage is available.

Is this the existing Dacity Coin project?

No. Dacity Labs is an independent project and separate token concept. It is not affiliated with Dacity Coin, Rockstar Games, or Grand Theft Auto.
